# Features

Specmatic provides a rich set of features to help you with contract-driven development:

* [Authentication](./authentication) - Configure authentication for your API tests
* [Dictionary](./dictionary) - Define reusable data dictionaries
* [External Examples](./external_examples) - Use external example files
* [Event Flow and Behaviour](./event_flow_and_behaviour) - Define event flows and behaviours
* [Overlays](./overlays) - Apply overlays to your specifications
* [Feature Hub Stubbing](./feature-hub-stubbing) - Stub FeatureHub feature flags
* [Hooks](./hooks/) - Extend Specmatic with custom hooks
* [JSON Schema](./json_schema/) - JSON Schema support including discriminators and anyOf
